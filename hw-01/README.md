# Демонстрационный стенд (Домашняя работа № 1)

Стенд для показа продукта клиентам, разворачиваемый средствами Yandex Cloud CLI.

## Архитектура
* **VPC:** `bashirov-04-net` с двумя подсетями в зонах `ru-central1-d` и `ru-central1-b`.
* **NAT-шлюз и Route Table:** обеспечивают закрытой подсети доступ в интернет для `cloud-init`.
* **Веб-серверы:** 3 инстанса `bashirov-04-web-*` на Ubuntu 24.04 c Nginx на порту `8012`.
* **Сервер приложения:** 1 инстанс `bashirov-04-app-1` **без публичного адреса** (доступен только внутри приватной сети).
* **Сетевой балансировщик (NLB):** слушает порт `80` и распределяет трафик на порт `8012` веб-серверов.

## Запуск и параметры
Поднять стенд (по умолчанию 3 веб-сервера):

```bash
./create.sh
```

## Проверка состояния

```bash
./create.sh --web-count 4
```

## Проверка состояния
Скрипт проверяет код ответа балансировщика, распределение и доступность внутреннего бэкенда:

```bash
./check.sh
echo $? # вернёт 0 при успехе, 1 при ошибке
```

## Удаление стенда
```bash
./destroy.sh
```
